## Editorial decisions and scope

- Opening answers the reader's actual question. Tables give facts; prose explains the consequences and next action.
- Minimal repeated caveats: one clear minimum-vs-competitive explanation, precise calculator interpretation, no repeated legalese in each paragraph.
-1500+ is an ambitious preparation goal in the tutoring context, not a Bocconi requirement. Do not advertise a tutoring programme for the Bocconi Test that has not been established; its article may link to SAT lessons only in the explicit alternative-SAT context or application help.
- No own tutor SAT score (latest user decision). Author: Marcin Zieliński, third-year International Economics and Management student;three years tutoring/dozens prepared confirmed by user.
- Separate theory from personal advice and illustrative arithmetic. A scoring example can use invented answer counts labelled as an illustration, not a student report.
- Dates, fees and rules verified today; keep current cycle and category visible and cite exact sources near relevant claims.
- ExistingCampus is an authored local prototype without a build pipeline; new guide sources and a deterministic builder will be added, leaving model/API code unchanged except serving the guide routes/assets.
