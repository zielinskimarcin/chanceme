# Prelint evaluation lab

Isolated evaluation of product-spec review on real Chance Me code.

This branch is not a release branch. Do not merge this branch or any evaluation PR into main. Vercel Git deployments are disabled in this branch configuration. No external email or database calls are needed for the lab.

Product requirements remain in AGENTS.md, docs/EMAIL-REPORTS.md and docs/REPORT-JOURNAL.md. Evaluation changes are compared against this fixed baseline; outcomes are recorded separately from the code under review. A control change and seeded defects are used to distinguish useful findings from false alarms.

Source baseline: 99aefb460de1146c2043ee8ca47d0b341e71d527.
